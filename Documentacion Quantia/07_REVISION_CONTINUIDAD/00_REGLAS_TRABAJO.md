# Reglas de trabajo — Revisión y continuidad

[[00_INDICE|← Índice]]

Esta carpeta documenta trabajo en curso. No reemplaza contratos canónicos ni schemas ejecutables.

```text
FUENTE TÉCNICA
→ REVISIÓN
→ PRUEBA
→ RESULTADO
→ DECISIÓN
→ CAMBIO VALIDADO
→ CONTRATO / ESTADO CANÓNICO
```

- No cerrar una etapa sólo porque una prueba pasa.
- No mezclar resultados experimentales con validados.
- Cada cambio importante debe registrar commit o punto de retorno.
- Cada resultado debe indicar archivo/prueba/evidencia.
- No recrear schemas ejecutables desde documentación narrativa.
- Mantener una sola fuente técnica vigente por componente.
- Evitar duplicar archivos grandes si Git ya conserva la versión.
- ZIP/checkpoints sólo cuando aporten un retorno que Git no cubra.
